# HR Data Analysis Dashboard

## 📊 Project Overview
An HR data analysis project built using Microsoft Excel to analyze employee demographics, performance, compensation, tenure, and pay gaps.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Data Cleaning
- Data Analysis

## 📈 Key Analysis
- Employee demographics
- Employee performance
- Compensation analysis
- Employee tenure
- Pay gap analysis
